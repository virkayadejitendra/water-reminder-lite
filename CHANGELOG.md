# Change Log

All notable changes to Water Reminder Lite are documented here.

## 0.2.0 - 2026-10-21

- Added the animated Hydration Buddy to the Explorer sidebar.
- Added a live countdown and quick Drink, Snooze, Pause, and Start actions.
- Added theme-aware colors and reduced-motion accessibility support.
- Added Marketplace metadata and artwork.

## 0.1.0 - 2026-10-21

- Initial release with configurable reminders, pause, snooze, notifications,
  command-palette controls, and a status-bar indicator.
