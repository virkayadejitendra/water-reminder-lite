# Support

Water Reminder Lite is maintained through its public GitHub repository.

- Report a bug: <https://github.com/virkayadejitendra/water-reminder-lite/issues>
- Review the source: <https://github.com/virkayadejitendra/water-reminder-lite>

When reporting a problem, include your VS Code version, extension version,
operating system, and the steps needed to reproduce it. Do not include secrets,
access tokens, or private workspace content.
